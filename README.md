# Harness Atlas

A visual, bilingual (EN / RU) map of AI harnesses: the 12 parts around a model, which ones each role needs, common pains and their fixes, and maturity levels.

Single static page: `index.html`. All content lives in the data block at the top of its script (`BLOCKS`, `ROLES`, `PAINS`, `LEVELS`, `CASES`), so adding a role or a case is one entry.
